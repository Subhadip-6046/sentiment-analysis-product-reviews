# Sentiment Analysis of Product Reviews

A machine learning project that analyses product reviews and classifies them as Positive or Negative.

## Models Used
- Multinomial Naive Bayes
- Support Vector Machine (SVM)
- Long Short-Term Memory (LSTM)

## Technologies
- Python
- Scikit-learn
- TensorFlow / Keras
- Pandas and NumPy
- Streamlit (Web Application)

## Features
- Product review sentiment classification
- TF-IDF text feature extraction
- Machine learning model comparison
- Rule-based correction for selected negation phrases

## Project Status
The machine learning models are developed, and the Streamlit web application is being prepared.
